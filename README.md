# Script PHP5 commentati

➡️ Corso correlato: **[Introduzione a PHP5 attraverso esempi](https://stahe.github.io/it-php5-juillet-2011/)**

---

## Panoramica

Questo documento offre una **raccolta di script PHP5** che coprono vari ambiti di applicazione del linguaggio. Non si tratta di un corso completo, ma piuttosto di una **raccolta di esempi pratici** intesi a illustrare alcune caratteristiche di PHP5 e a fungere da base per la sperimentazione da parte degli sviluppatori.

Gli script presentati sono:
- commentati direttamente all'interno del codice;
- accompagnati dal **loro output in console**;
- talvolta integrati da **spiegazioni aggiuntive** per aiutare a comprenderne meglio il funzionamento.

L'obiettivo di questo documento è offrire un **approccio pratico al linguaggio PHP5**, basato sullo studio e l'analisi degli script.

---

## Destinatari

Questo documento è destinato agli sviluppatori che hanno **già utilizzato un linguaggio di scripting**, come:

- Perl;
- Python;
- VBScript;

Si presuppone quindi una **certa familiarità con i concetti di scripting**.

I lettori privi di questa esperienza pregressa dovrebbero invece iniziare con un **corso completo su PHP** prima di utilizzare questa raccolta di esempi.

---

## Metodo di lettura

Questo documento richiede una **lettura attiva**:

1. Leggi il codice dello script.
2. Esamina i commenti incorporati.
3. Studia i risultati di esecuzione forniti.

È la combinazione di questi tre elementi che ti permette di comprendere appieno ogni esempio.
