    9. Le funzioni di rete di PHP

    Passiamo ora alle funzioni di rete di PHP che ci consentono di effettuare la programmazione TCP / IP (Transfer Control Protocol / Internet Protocol).

    9.1. Ottenere il nome o l’indirizzo IP di un computer su Internet (inet_01)

    
<?php

// funzioni nome macchina <--> indirizzo IP macchina
ini_set("display_errors", "off");
// costanti
$HOTES = array("istia.univ-angers.fr", "www.univ-angers.fr", "www.ibm.com", "localhost", "", "xx");
// indirizzi IP delle macchine di $HOTES
for ($i = 0; $i < count($HOTES); $i++) {
  getIPandName($HOTES[$i]);
}
// fine
exit;

//------------------------------------------------
function getIPandName($nomMachine) {
//$nomMachine: nome della macchina di cui si desidera l'indirizzo IP
// nomMachine-->indirizzo IP
  $ip = gethostbyname($nomMachine);
  if ($ip != $nomMachine) {
    print "ip[$nomMachine]=$ip\n";
// indirizzo IP --> nomMachine
    $name = gethostbyaddr($ip);
    if ($name != $ip) {
      print "name[$ip]=$name\n";
    } else {
      print "Erreur, machine[$ip] non trouvée\n";
    }
  } else {
    print "Erreur, machine[$nomMachine] non trouvée\n";
  }
}

    • riga 18: la funzione gethostbyname($nom) consente di ottenere l'indirizzo IP "ip3.ip2.ip1.ip0" del computer denominato $nom. Se la macchina $nom non esiste, la funzione restituisce $nom come risultato.

    9.2. Un client web ( inet_02)

    Uno script che consente di ottenere il contenuto della pagina indice di un sito web.

    
<?php

// gestione degli errori
ini_set("display_errors","off");
// ottenere il testo HTML da URL
// elenco dei siti web
$SITES = array("istia.univ-angers.fr", "www.univ-angers.fr", "www.ibm.com", "xx");
// lettura delle pagine indice dei siti della tabella $SITES
for ($i = 0; $i < count($SITES); $i++) {
// lettura della pagina indice del sito $SITES[$i]
  $résultat = getIndex($SITES[$i]);
// visualizzazione del risultato
  print "$résultat\n";
}//per
// fine
exit;

//-----------------------------------------------------------------------
function getIndex($site) {
// legge il file URL $site/ e lo salva nel file $site.html
// creazione del file $site.html
  $html = fopen("$site.html", "w");
  if (!$html)
    return "Erreur lors de la création du fichier $site.html";

// apertura di una connessione sulla porta 80 di $site
  $connexion = fsockopen($site, 80);
// ritorno in caso di errore
  if (!$connexion)
    return "Echec de la connexion au site ($site,80) : $erreur";
// $connexion rappresenta un flusso di comunicazione bidirezionale
// tra il client (questo programma) e il server web contattato
// questo canale viene utilizzato per lo scambio di comandi e informazioni
// il protocollo di comunicazione è HTTP
// il client invia il comando GET per richiedere l'URL /
// sintassi GET URL HTTP/1.0
// le intestazioni (header) del protocollo HTTP devono terminare con una riga vuota
  fputs($connexion, "GET / HTTP/1.0\n\n");
// il server risponderà ora sul canale $connexion. Invierà tutti
// questi dati e poi chiuderà il canale. Il client legge quindi tutto ciò che arriva da $connexion
// fino alla chiusura del canale
  while ($ligne = fgets($connexion, 1000))
    fputs($html, $ligne);
// il client chiude a sua volta la connessione
  fclose($connexion);
// chiusura del file $html
  fclose($html);
// ritorno
  return "Transfert réussi de la page index du site $site";
}

    • riga 7: l’elenco degli URL dei siti web di cui si desidera la pagina iniziale. Questa verrà salvata nel file di testo [nomsite.html].
    • riga 11: la funzione getIndex esegue l'operazione
    • riga 19: la funzione getIndex($site) scarica la pagina radice (o pagina iniziale) del sito web $site e la salva nel file di testo $site.html.
    • riga 27: la funzione fsockopen($site,$port) consente di creare una connessione con un servizio TCP / IP operante sulla porta $port del computer $site. Una volta aperta la connessione client/server, numerosi servizi TCP / IP scambiano righe di testo. È il caso, in questo contesto, del protocollo HTTP (HyperText Transfer Protocol). Il flusso proveniente dal server e in arrivo al client può quindi essere trattato come un file di testo. Lo stesso vale per il flusso in uscita dal client verso il server.
    • riga 38: la funzione fputs consente al client di inviare dati al server. In questo caso, la riga di testo inviata ha il seguente significato: «Voglio (GET) la pagina radice (/) del sito web a cui sono connesso. Sto utilizzando il protocollo HTTP versione 1.0". La versione attuale di questo protocollo è la 1.1.
    • riga 42: le righe di testo della risposta del server possono essere lette riga per riga con un ciclo while e salvate nel file di testo [$site.html]. Quando il server web ha inviato la pagina richiesta, chiude la connessione con il client. Dal lato client, ciò verrà rilevato come fine del file.

    9.3. Un client SMTP (inet_03)

    Tra i protocolli TCP / IP, SMTP (SendMail Transfer Protocol) è il protocollo di comunicazione del servizio di invio dei messaggi.

    Note:

    • su un computer Windows dotato di antivirus, quest’ultimo probabilmente impedirà allo script PHP di connettersi alla porta 25 di un server SMTP. È quindi necessario disattivare l’antivirus. Per McAfee, ad esempio, è possibile procedere come segue:

    • in [2], si arresta il servizio [Protection lors de l'accès]

<?php

// client SMTP (protocollo di trasferimento SendMail) che consente di inviare un messaggio
// le informazioni vengono prelevate da un file $INFOS contenente le seguenti righe
// riga 1: smtp, mittente, destinatario
// righe successive: il testo del messaggio
// mittente: email del mittente
// destinatario: email del destinatario
// smtp: nome del server smtp da utilizzare
// protocollo di comunicazione client-server SMTP
// -> il client si connette alla porta 25 del server SMTP
// <- il server gli invia un messaggio di benvenuto
// -> il client invia il comando EHLO: nome del proprio computer
// <- il server risponde con OK oppure no
// -> il client invia il comando mail from: <mittente>
// <- il server risponde con OK oppure no
// -> il client invia il comando rcpt a: <destinatario>
// <- il server risponde con OK oppure no
// -> il client invia il comando data
// <- il server risponde con OK oppure no
// -> il client invia tutte le righe del proprio messaggio e termina con una riga contenente il
// unico carattere.
// <- il server risponde con OK oppure no
// -> il client invia il comando quit
// <- il server risponde con OK oppure no
// le risposte del server hanno il formato xxx testo, dove xxx è un numero a 3 cifre. Qualsiasi numero xxx >=500
// segnala un errore. La risposta può comprendere più righe, tutte inizianti con xxx tranne l'ultima
// del formato xxx(spazio)
// le righe di testo scambiate devono terminare con i caratteri RC(#13) e LF(#10)

// dati
$INFOS = "mail.txt"; // i parametri di invio dell'e-mail
// si recuperano i parametri della posta
list($erreur, $smtpServer, $expéditeur, $destinataire, $message) = getInfos($INFOS);
// errore?
if ($erreur) {
  print "$erreur\n";
  exit;
}
print "Envoi du message [$smtpServer,$expéditeur,$destinataire]\n";
// invio dell'e-mail in modalità verbosa
$résultat = sendmail($smtpServer, $expéditeur, $destinataire, $message, 1);
print "Résultat de l'envoi : $résultat\n";
// fine
exit;

//-----------------------------------------------------------------------
function getInfos($fichier) {
// restituisce le informazioni ($smtp,$expéditeur,$destinataire,$message) dal file di testo $fichier
// riga 1: smtp, mittente, destinatario
// righe successive: il testo del messaggio

// apertura di $fichier
  $infos = fopen($fichier, "r");
// il file $fichier esiste
  if (!$infos)
    return array("Le fichier $fichier n'a pu être ouvert en lecture");
// lettura della prima riga
  $ligne = fgets($infos, 1000);
// rimozione del carattere di fine riga
  $ligne = cutNewLineChar($ligne);
// recupero dei campi smtp, mittente, destinatario
  $champs = explode(",", $ligne);
// il numero di campi è corretto?
  if (count($champs) != 3)
    return "La ligne 1 du fichier $fichier (serveur smtp, expéditeur, destinataire) a un
nombre de champs incorrect";
// "elaborazione" delle informazioni recuperate
  for ($i = 0; $i < count($champs); $i++)
    $champs[$i] = trim($champs[$i]);
// recupero dei campi
  list($smtpServer, $expéditeur, $destinataire) = $champs;
// lettura del messaggio
  $message = "";
  while ($ligne = fgets($infos, 1000))
    $message.=$ligne;
  fclose($infos);
// ritorno
  return array("", $smtpServer, $expéditeur, $destinataire, $message);
}

//-----------------------------------------------------------------------

function sendmail($smtpServer, $expéditeur, $destinataire, $message, $verbose) {
// invia $message al server SMTP $smtpserver a nome di $expéditeur
// per $destinataire. Se $verbose=1, esegue il monitoraggio degli scambi client-server
// si recupera il nome del client
  $client = gethostbyaddr(gethostbyname(""));
// apertura di una connessione sulla porta 25 di $smtpServer
  $connexion = fsockopen($smtpServer, 25);
// ritorno in caso di errore
  if (!$connexion)
    return "Echec de la connexion au site ($smtpServer,25)";
// $connexion rappresenta un flusso di comunicazione bidirezionale
// tra il client (questo programma) e il server SMTP contattato
// questo canale viene utilizzato per lo scambio di comandi e informazioni

// dopo la connessione, il server invia un messaggio di benvenuto che viene letto
  $erreur = sendCommand($connexion, "", $verbose, 1);
  if ($erreur) {
    fclose($connexion);
    return $erreur;
  }

// comando EHLO:
  $erreur = sendCommand($connexion, "EHLO $client", $verbose, 1);
  if ($erreur) {
    fclose($connexion);
    return $erreur;
  }

// comando mail from:
  $erreur = sendCommand($connexion, "MAIL FROM: <$expéditeur>", $verbose, 1);
  if ($erreur) {
    fclose($connexion);
    return $erreur;
  }

// comando rcpt to:
  $erreur = sendCommand($connexion, "RCPT TO: <$destinataire>", $verbose, 1);
  if ($erreur) {
    fclose($connexion);
    return $erreur;
  }

// comando data
  $erreur = sendCommand($connexion, "DATA", $verbose, 1);
  if ($erreur) {
    fclose($connexion);
    return $erreur;
  }

// preparazione del messaggio da inviare
  // deve contenere le righe
  // Da: mittente
  // A: destinatario
  // riga vuota
  // Messaggio
  // .
  $data = "From: $expéditeur\r\nTo: $destinataire\r\n$message\r\n.\r\n";
  $erreur = sendCommand($connexion, $data, $verbose, 0);
  if ($erreur) {
    fclose($connexion);
    return $erreur;
  }

// comando quit
  $erreur = sendCommand($connexion, "QUIT", $verbose, 1);
  if ($erreur) {
    fclose($connexion);
    return $erreur;
  }

// fine
  fclose($connexion);
  return "Message envoyé";
}

// --------------------------------------------------------------------------

function sendCommand($connexion, $commande, $verbose, $withRCLF) {
// invia $commande nel canale $connexion
// modalità verbosa se $verbose=1
// se $withRCLF=1, aggiunge la sequenza RCLF allo scambio

// dati
  if ($withRCLF)
    $RCLF = "\r\n"; else
    $RCLF="";

// invio comando se $commande non è vuoto
  if ($commande) {
    fputs($connexion, "$commande$RCLF");

// eventuale eco
    if ($verbose)
      affiche($commande, 1);
  }//se

// lettura della risposta
  $réponse = fgets($connexion, 1000);

// eventuale eco
  if ($verbose)
    affiche($réponse, 2);

// recupero codice di errore
  $codeErreur = substr($réponse, 0, 3);

// ultima riga della risposta?
  while (substr($réponse, 3, 1) == "-") {

     // lettura risposta
    $réponse = fgets($connexion, 1000);

     // eventuale eco
    if ($verbose)
      affiche($réponse, 2);
  }//while
// risposta terminata

// errore restituito dal server?
  if ($codeErreur >= 500)
    return substr($réponse, 4);

// ritorno senza errori
  return "";
}

    case 1:
      print "--> [$échange]\n";
      return;
    case 2:
      $L = strlen($échange);
      print "<-- [" . substr($échange, 0, $L - 2) . "]\n";
      return;
  }//switch
}

    9.4. Un secondo programma per l’invio di e-mail (inet_04)

    Questo script ha la stessa funzionalità del precedente: inviare un’e-mail. A tal fine utilizziamo i moduli della libreria PEAR. Questa libreria comprende decine di moduli che coprono diversi ambiti. Utilizzeremo i seguenti:

    • Net/SMTP: un modulo che consente di interagire con un server SMTP

    Commenti

    Lo script differisce dal precedente solo per la funzione sendmail. Di seguito ne forniamo una descrizione:

    • riga 6: gli script PHP dei moduli PEAR sono stati installati in una directory che, per impostazione predefinita, non viene esplorata dall’interprete PHP. Affinché quest'ultimo possa individuare i moduli PEAR, definiamo noi stessi le cartelle che l'interprete PHP deve esplorare. È possibile modificare durante l'esecuzione alcuni parametri di configurazione dell'interprete PHP. Tale modifica è visibile solo allo script che la effettua e solo per la durata della sua esecuzione. La configurazione predefinita dell’interprete PHP si trova nel file <PHP_installdir>/PHP.ini. Questo file contiene righe della forma 
    clé=valeur

    Il valore della chiave può essere modificato in fase di esecuzione tramite la funzione ini_set(chiave, nouvelle_valeur). La chiave per specificare il percorso di ricerca da parte dell’interprete delle funzioni e delle classi PHP a cui fa riferimento lo script è 'include_path'. In questo caso, inseriamo nel percorso di ricerca sia la cartella dello script (.) sia la cartella PEAR della cartella di installazione dell'interprete PHP.

    • righe 7-9: vengono caricati gli script PHP per l'invio delle e-mail.
    • riga 50: la funzione sendmail che si occupa di inviare l’e-mail. I suoi parametri sono i seguenti:
      • $smtpServer: il nome del server SMTP a cui connettersi
      • $expéditeur: l'indirizzo e-mail del mittente
      • $destinataire: l'indirizzo e-mail del destinatario
      • $message: il messaggio da inviare.
      • $sujet: l'oggetto del messaggio
      • $attachement: il nome del documento da allegare al messaggio

    La funzione sendMail restituisce un messaggio di errore, vuoto se non si sono verificati errori.

    • riga 56: creazione di un messaggio di tipo Mail_Mime. Questo messaggio è composto da intestazioni (From, To, Subject) e da un corpo (il messaggio stesso)
    • riga 57: si imposta il corpo del messaggio Mail_Mime.
    • riga 58: si allega un documento al messaggio
    • riga 59: si impostano le intestazioni (From, To, Subject) del messaggio Mail_Mime
    • riga 61: si crea la classe incaricata di inviare il messaggio Mail_Mime. Il primo parametro del metodo è il nome del protocollo da utilizzare, in questo caso il protocollo SMTP. Il secondo parametro è un array che specifica il nome e la porta del servizio SMTP da utilizzare
    • riga 62: invio del messaggio. Il metodo send riceve tre parametri: l'indirizzo del mittente, le intestazioni del messaggio Mail_Mime e il corpo del messaggio Mail_Mime. La funzione send restituisce il valore booleano TRUE se l'invio è andato a buon fine, altrimenti restituisce un messaggio di errore.
