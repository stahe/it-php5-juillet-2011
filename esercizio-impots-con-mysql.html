    8.2. Il programma di calcolo delle imposte ( impots_04)

    Questa versione utilizza una classe Impôts che recupera da un database i valori necessari per il calcolo dell'imposta. Introduciamo qui un nuovo concetto, quello di query preparata. L’esecuzione di un comando SQL tramite un SGBD avviene in due fasi:

    1. la query viene preparata: il SGBD preparerà un piano di esecuzione ottimizzato per la query. L'obiettivo è eseguirla nel modo più efficiente possibile.
    1. la query viene eseguita.

    Se una stessa query viene eseguita N volte, le due fasi precedenti vengono ripetute N volte. È tuttavia possibile preparare la query una sola volta ed eseguirla N volte. A tal fine è necessario utilizzare le query preparate. Se $requête è il comando SQL da eseguire e $connexion è l’oggetto PDO che rappresenta la connessione:

    • $statement=$connexion->prepare($requête) prepara una query e restituisce la query "preparata"
    • $statement->execute() esegue la query preparata.

    Se la query preparata è un comando select, allora

    • $statement->fetchAll() restituisce tutte le righe della tabella risultante da select sotto forma di un array T, dove T[i,j] è il valore della colonna j della riga i della tabella
    • $statement->fetch() restituisce la riga corrente della tabella sotto forma di un array T, dove T[j] è il valore della colonna j della riga

    La query preparata offre altri vantaggi oltre a una maggiore efficienza. In particolare, garantisce una maggiore sicurezza. Pertanto, dovrebbe essere utilizzata sistematicamente.
