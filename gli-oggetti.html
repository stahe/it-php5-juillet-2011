    5. Gli oggetti

    5.1. Qualsiasi variabile può diventare un oggetto dotato di attributi (exemple_14)

    
<?php

// ogni variabile può avere attributi per definizione
$obj1->attr1 = "un";
$obj1->attr2 = 100;
// visualizza l'oggetto
print "objet1=[$obj1->attr1,$obj1->attr2]\n";
// modifica l'oggetto
$obj1->attr2+=100;
// visualizza l'oggetto
print "objet1=[$obj1->attr1,$obj1->attr2]\n";
// assegna il valore di oggetto1 a oggetto2
$obj2 = $obj1;
// modifica obj2
$obj2->attr2 = 0;
// visualizza entrambi gli oggetti
print "objet1=[$obj1->attr1,$obj1->attr2]\n";
print "objet2=[$obj2->attr1,$obj2->attr2]\n";
// assegna il riferimento di oggetto1 a oggetto3
$obj3 = &$obj1;
// modifica obj3
$obj3->attr2 = 10;
// visualizza entrambi gli oggetti
print "objet1=[$obj1->attr1,$obj1->attr2]\n";
print "objet3=[$obj3->attr1,$obj3->attr2]\n";
// un oggetto è un dizionario?
print count($obj1)."\n";
while (list($attribut, $valeur) = each($obj1))
  print "obj1[$attribut]=$valeur\n";
// fine
exit;
?>

    Risultati:

    objet1=[un,100]
objet1=[un,200]
objet1=[un,0]
objet2=[un,0]
objet1=[un,10]
objet3=[un,10]
1
obj1[attr1]=un
obj1[attr2]=10

    Commenti

    • riga 4: la notazione $obj->attr indica l'attributo attr della variabile $obj. Se non esiste, viene creato, trasformando così la variabile $obj in un oggetto con attributi.
    • riga 13: l'espressione $obj2=$obj1, quando $obj1 è un oggetto, rappresenta una copia di oggetti per riferimento. Pertanto, $obj2 e $obj1 sono riferimenti allo stesso oggetto. L’oggetto stesso può essere modificato tramite uno qualsiasi dei due riferimenti.
    • riga 20: l'espressione $obj3=&$obj1 assegna a $obj3 il riferimento (l'indirizzo) della variabile $obj1. Se $obj1 è un oggetto, come in questo caso, l'espressione precedente è equivalente a $obj3=$obj1.
    • righe 28-29: mostrano che un oggetto può essere iterato come un dizionario. Le chiavi del dizionario sono i nomi degli attributi e i valori del dizionario sono i valori di questi stessi attributi.
    • riga 27: la funzione count può essere applicata a un oggetto ma non restituisce, come ci si sarebbe potuto aspettare, il numero di attributi. Pertanto, un oggetto presenta delle somiglianze con un dizionario ma non ne è uno.

    5.2. Una classe Persona senza attributi dichiarati (exemple_15)

    
<?php

class Personne {

  // attributi della classe
  // non dichiarati - possono essere creati dinamicamente
  
  // metodo
  function identité() {
    // a prima vista, utilizza attributi inesistenti
    return "[$this->prénom,$this->nom,$this->âge]";
  }
}

// test
// gli attributi sono pubblici e possono essere creati dinamicamente
$p = new Personne();
$p->prénom = "Paul";
$p->nom = "Langevin";
$p->âge = 48;
// chiamata di un metodo
print "personne=" . $p->identité() . "\n";
// fine
exit;
?>

    Risultati:

    personne=[Paul,Langevin,48]

    Commenti

    • righe 3-13: definiscono una classe Personne. Una classe è uno stampo a partire dal quale si creano gli oggetti. Una classe è un insieme che raggruppa attributi e funzioni chiamate metodi. Non è obbligatorio dichiarare gli attributi.
    • righe 9-12: il metodo identité visualizza il valore di tre attributi non dichiarati nella classe. La parola chiave $this indica l’oggetto a cui si applica il metodo.
    • riga 17: si crea un oggetto $p di tipo Personne. La parola chiave new serve a creare un nuovo oggetto. L'operazione restituisce un riferimento all'oggetto creato (quindi un indirizzo). Sono possibili diverse sintassi: new Personne(), new Personne, new personne. Il nome della classe non fa distinzione tra maiuscole e minuscole.
    • righe 18-20: i tre attributi necessari al metodo identité vengono creati nell’oggetto $p.
    • riga 22: il metodo identité della classe Personne viene applicato all’oggetto $p. Nel codice (righe 9-11) del metodo identité, $this fa riferimento allo stesso oggetto di $p.

    5.4. La classe Persona con un costruttore (exemple_17)

    Gli esempi precedenti mostravano classi Personne insolite, come quelle che si potevano trovare in PHP 4. Non è consigliabile seguire questi esempi. Presentiamo ora una classe Personne conforme alle buone pratiche di PHP 5:

    
<?php

class Personne {

// attributi della classe
  private $prénom;
  private $nom;
  private $âge;

// getter e setter
  public function getPrénom() {
    return $this->prénom;
  }

  public function getNom() {
    return $this->nom;
  }

  public function getAge() {
    return $this->âge;
  }

  public function setPrénom($prénom) {
    $this->prénom = $prénom;
  }

  public function setNom($nom) {
    $this->nom = $nom;
  }

  public function setAge($age) {
    $this->âge = $age;
  }

// costruttore
  function __construct($prénom, $nom, $âge) {
    // si passa attraverso i set
    $this->setPrénom($prénom);
    $this->setNom($nom);
    $this->setAge($âge);
  }

// metodo toString
  function __toString() {
    return "[$this->prénom,$this->nom,$this->âge]";
  }

}

// test
// creazione di un oggetto persona
$p = new Personne("Paul", "Langevin", 48);
// identità di questa persona
print "personne=$p\n";
// si modifica l'età
$p->setAge(14);
// identità della persona
print "personne=$p\n";
// fine
exit;
?>

    Risultati:

    personne=[Paul,Langevin,48]
personne=[Paul,Langevin,14]

    Commenti

    • righe 3-48: la classe Personne
    • righe 6-8: gli attributi privati (private) della classe. Questi attributi sono visibili solo all'interno della classe. Le altre parole chiave utilizzabili sono:
    • public: rende l'attributo pubblico, visibile dall'esterno della classe
    • protected: rende l'attributo protetto, visibile dall'interno della classe e dalle classi da essa derivate.
    • Poiché gli attributi sono privati, non è possibile accedervi dall’esterno della classe. Non è quindi possibile scrivere il seguente codice:
    1
2
    $p=new Personne() ;
$p->nom="Landru" ;

    Qui ci si trova all'esterno della classe Personne. Poiché l'attributo nom è privato, la riga 2 è errata. Per inizializzare i campi privati dell'oggetto $p, ci sono due modi:

    • (continua)
      • utilizzare i metodi pubblici set e get (il nome di questi metodi può essere qualsiasi) delle righe 11-33. Si potrà quindi scrivere:
    1
2
    $p=new Personne() ;
$p->setNom("Landru") ;
    • (continua)
      • utilizzare il costruttore delle righe 36-41. Si scriverà quindi:
    1
    $p=new Personne("Michel","Landru",44) ;

    Il codice sopra riportato richiama automaticamente il metodo della classe Personne denominato __construct.

    • riga 54: questa riga visualizza la persona $p sotto forma di stringa di caratteri. A tal fine, viene utilizzato il metodo della classe Personne denominato __toString.

    5.5. La classe Persona con controllo di validità nel costruttore (exemple_18)

    Il costruttore di una classe è il luogo ideale per verificare che i valori di inizializzazione dell’oggetto siano corretti. Tuttavia, un oggetto può essere inizializzato anche tramite i propri metodi set o equivalenti. Per evitare di inserire le stesse verifiche in due punti diversi, queste ultime verranno inserite nei metodi set. Se un valore di inizializzazione di un oggetto risulta errato, verrà generata un’eccezione. Ecco un esempio:

    
<?php

class Personne {

// attributi della classe
  private $prénom;
  private $nom;
  private $âge;
  
// getter e setter
  public function getPrénom() {
    return $this->prénom;
  }

  public function getNom() {
    return $this->nom;
  }

  public function getAge() {
    return $this->âge;
  }

  public function setPrénom($prénom) {
    // il nome deve essere diverso da vuoto
    if (!preg_match("/^\s*(.+?)\s*$/", $prénom, $champs)) {
      throw new Exception("Le prénom doit être non vide");
    } else {
      $this->prénom = $champs[1];
    }
  }

  public function setNom($nom) {
    // il cognome deve essere non vuoto
    if (!preg_match("/^\s*(.+?)\s*$/", $nom, $champs)) {
      throw new Exception("Le nom doit être non vide");
    } else {
      $this->nom = $champs[1];
    }
  }

  public function setAge($âge) {
    // l'età deve essere valida
    if (!preg_match("/^\s*(\d+)\s*$/", $âge, $champs)) {
      throw new Exception("L'âge doit être un entier positif ou nul");
    } else {
      $this->âge = $champs[1];
    }
  }

// costruttore
  function __construct($prénom, $nom, $âge) {
    // si utilizzano i set
    $this->setPrénom($prénom);
    $this->setNom($nom);
    $this->setAge($âge);
  }

  // metodo toString
  function __toString() {
    return "[$this->prénom,$this->nom,$this->âge]";
  }
}

// test
// creazione di un oggetto Persona
$p = new Personne("Paul", "Langevin", 48);
// identità di questa persona
print "personne=$p\n";
// creazione errata di un oggetto Persona
try {
  $p = new Personne("xx", "yy", "zz");
} catch (Exception $e) {
  print $e->getMessage();
}
// fine
exit;
?>

    Risultati:

    personne=[Paul,Langevin,48]
L'âge doit être un entier positif ou nul

    Commenti

    • righe 23-30: inizializzazione dell'attributo prénom e verifica del valore di inizializzazione
    • riga 25: utilizzo di un'espressione regolare. Il nome è una sequenza di uno o più caratteri, eventualmente preceduta o seguita da spazi.
    • riga 26: se il cognome è vuoto, viene generata un'eccezione; altrimenti il nome viene memorizzato (riga 28)
    • riga 66: utilizzo del costruttore della classe Personne
    • riga 68: utilizzo del metodo __toString della classe Personne
    • righe 70-74: gestione dell'eventuale eccezione generata dal costruttore della classe Personne.

    5.6. Aggiunta di un metodo che funge da secondo costruttore (exemple_19)

    In PHP 5, non è possibile avere più costruttori con parametri diversi che consentano di creare un oggetto in vari modi. È quindi possibile utilizzare metodi che fungono da costruttori:

    
<?php

class Personne {

// attributi della classe
  private $prénom;
  private $nom;
  private $âge;
  
// getter e setter
  public function getPrénom() {
    return $this->prénom;
  }

….

// costruttore
  function __construct($prénom, $nom, $âge) {
    // si passa tramite i set
    $this->setPrénom($prénom);
    $this->setNom($nom);
    $this->setAge($âge);
  }

  // metodo
  public function initWithPersonne($p) {
    // inizializza l'oggetto corrente con una persona $p
    $this->__construct($p->prénom, $p->nom, $p->âge);
  }

  // metodo toString
  function __toString() {
    return "[$this->prénom,$this->nom,$this->âge]";
  }

}

// test
// creazione di un oggetto Persona
$p = new Personne("Paul", "Langevin", 48);
// identità di questa persona
print "personne=$p\n";
// creazione di una seconda persona
$p2 = new Personne("Laure", "Adeline", 67);
// inizializzazione della prima con i valori della seconda
$p->initWithPersonne($p2);
// verifica
print "personne=$p\n";
// fine
exit;
?>

    Risultati:

    personne=[Paul,Langevin,48]
personne=[Laure,Adeline,67]

    Commenti

    • righe 26-29: il metodo initWithPersonne consente di assegnare all'oggetto corrente i valori degli attributi di un altro oggetto Personne. In questo caso, richiama il costruttore __construct, ma ciò non è obbligatorio.

    5.10. Le interfacce (exemple_23)

    Un'interfaccia è una struttura che definisce i prototipi dei metodi. Una classe che implementa un'interfaccia definisce il codice di tutti i metodi dell'interfaccia.

    
<?php

// un'interfaccia
interface IExemple {
  function ajouter($i, $j);

  function soustraire($i, $j);
}

// implementazione 1 dell'interfaccia
class Classe1 implements IExemple {

  public function ajouter($a, $b) {
    return $a + $b + 10;
  }

  public function soustraire($a, $b) {
    return $a - $b + 20;
  }

}

// implementazione 2 dell'interfaccia
class Classe2 implements IExemple {

  public function ajouter($a, $b) {
    return $a + $b + 100;
  }

  public function soustraire($a, $b) {
    return $a - $b + 200;
  }

}

// funzione
function calculer($a, $b, IExemple $interface) {
  print $interface->ajouter($a, $b)."\n";
  print $interface->soustraire($a, $b)."\n";
}

$c1 = new Classe1();
$c2 = new Classe2();
// chiamata della funzione calcolare
calculer(4, 3, $c1);

    Commenti

    • righe 4-8: l'interfaccia IExemple definisce due metodi: la funzione ajouter (riga 5) e la funzione soustraire (riga 7). L'interfaccia non definisce il codice di questi metodi. Saranno le classi che implementano l'interfaccia a farlo.
    • riga 11: la classe Classe1 implementa l'interfaccia IExemple. Definisce quindi un codice per i metodi ajouter (riga 13) e soustraire (riga 17).
    • righe 24-34: lo stesso vale per la classe Classe2
    • riga 37: il metodo calculer accetta tre parametri: due numeri interi $a e $b e un oggetto $interface che implementa l'interfaccia IExemple. Si sarebbe potuto scrivere function calculer($a,$b,$interface) senza specificare il tipo IExemple del parametro $interface. Indicandolo, si consente all’interprete PHP di verificare che il parametro effettivo sia effettivamente un oggetto che implementa l’interfaccia IExemple.
    • righe 38-39: utilizzo dei metodi ajouter e soustraire dell'oggetto $interface. Poiché quest’ultimo implementa l’interfaccia IExemple, sappiamo che possiede questi due metodi.
    • righe 44-45: creazione di due oggetti di tipi diversi ma che implementano entrambi l'interfaccia IExemple.
    • riga 47: si passa alla funzione calculer, passando l’oggetto $c1 di tipo Classe1 che implementa l’interfaccia IExemple.
    • riga 48: si passa alla funzione calculer, l'oggetto $c2 di tipo Classe2 che implementa l'interfaccia IExemple.
